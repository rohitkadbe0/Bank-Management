## BANK MANAGEMENT
-	Developed a backend banking application to manage customers, accounts, cards, loans, and transactions using Java and Spring Boot.
-	Implemented secure user authentication and role-based access control with Spring Security and password encryption.
-	Built RESTful APIs for account management, fund transfers, deposits, withdrawals, and loan processing.
-	Applied business validation rules for account creation, loan eligibility, and card issuance.
-	Integrated MongoDB for data persistence and JavaMailSender for automated card expiry notifications.
